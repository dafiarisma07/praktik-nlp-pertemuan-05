# Praktik NLP — Pertemuan 05
## Anotasi Sentimen dan Representasi TF-IDF

### 1. Tujuan
Melakukan anotasi sentimen pada dataset ulasan, memeriksa kualitas data, membagi dataset, dan mempelajari representasi teks menggunakan TF-IDF.

### 2. Anotasi Dataset
Dataset berisi 60 ulasan sintetis. Setiap ulasan diberi label sentimen, aspek, dan alasan berdasarkan isi teks.

### 3. Audit dan Pembagian Data
Pemeriksaan dilakukan terhadap data kosong, alasan kosong, dan duplikasi setelah normalisasi. Dataset kemudian dibagi menjadi data latih, validasi, dan data uji dengan rasio 70:15:15 dan seed 42.

Hasil audit dan jumlah data pada setiap bagian dicatat berdasarkan keluaran aplikasi.

### 4. Representasi TF-IDF
Perbandingan dilakukan pada kalimat “Pelayanan tidak bagus” dan “Pelayanan bagus” untuk mengamati representasi kata dan pengaruh kata negasi.

- File eksperimen JSON
- File dataset CSV
- Screenshot audit dataset & pembagian data
- Screenshot perbandingan TF-IDF

### 6. Kesimpulan
Praktik ini memberikan pengalaman dalam anotasi sentimen, pemeriksaan kualitas dataset, pembagian data, dan representasi teks menggunakan TF-IDF.
